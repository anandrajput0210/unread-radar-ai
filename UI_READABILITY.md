# UI readability and card polish

This update raises the smallest interface labels and metadata to 11–12 px, uses more comfortable line spacing, and keeps task titles at the existing readable body size. The smallest labels include status/context markers and evidence action links.

Task cards and priority cards now use:
- More consistent 16–24 px corner radii.
- More generous internal spacing.
- Clearer neutral borders and layered dark surfaces.
- Restrained shadows to separate cards from the background.
- Subtle hover elevation/border feedback on desktop.

Source quotations and related conversation context have more padding and clearer grouping so evidence is easier to scan. No new color meaning or new product workflow was introduced.
