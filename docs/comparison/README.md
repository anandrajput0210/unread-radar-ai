# Recorded comparisons

The manifest is intentionally empty until a real comparison run has been completed.

To add a real run:

1. Paste the selected trap chat into a general-purpose AI tool.
2. Record the tool name, model name, run date, and exact prompt used.
3. Save the tool's complete output verbatim and capture a screenshot.
4. Add a manifest entry with the trap chat ID, recorded metadata, exact prompt, verbatim output, screenshot path, and any relevant notes.

Keep the prompt and output unchanged. Do not add a comparison entry based on an estimate, recollection, or generated example. Store screenshots beside the manifest and use a relative `screenshotPath`.
